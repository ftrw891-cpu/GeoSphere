# Geosphere

E-learning bangun ruang (kubus & balok). Satu halaman statis (`index.html`).

## Deploy ke Netlify
1. Unggah semua file ini ke repository GitHub.
2. Di Netlify: Add new site → Import from Git → pilih repository ini.
3. Build command: kosongkan. Publish directory: `.` (sudah diatur di `netlify.toml`).

## Catatan
- Data masih disimpan di memori browser (hilang saat dimuat ulang). Tahap berikutnya: Supabase.
- Pembayaran dan Tutor AI masih simulasi.
- Kode admin demo masih tertanam di kode; ganti dengan Supabase Auth sebelum dipakai siswa sungguhan.
